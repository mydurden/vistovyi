# ZS-154: галочка закриває збережену картку (vistovyi-v66)

Автор `++`. Prefs не чіпали. Паралельно ZS-153 (модаль Архіву) — UI Архіву в профілі не змінювали.

## Поведінка

- **Збережена картка о/с / ОВТ** (той самий хром у оверлеї):
  - зелена **галочка** комітить правки (якщо були) і **закриває** вікно — без архіву/видалення;
  - червоний **хрестик** лише **закриває** вікно («повернутись») — без архіву;
  - архів лишається **окремим шляхом** (свайп рядка → «В архів» + підтвердження).
- **Чернетка** (нова незбережена): без змін задуму — хрестик скасовує, галочка/закриття оверлея зберігають заповнене.
